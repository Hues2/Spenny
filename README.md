# Spenny

## Introduction

**Spenny** is one of my first iOS applications built using **SwiftUI**. It allows users to effortlessly keep track of their spending with an easy-to-use interface. The app is developed using Swift and SwiftUI, and it also utilizes the Combine and Core Data frameworks for reactive programming and data persistence.

## Features

- **Monthly Balance Tracking:** Keep an eye on your remaining monthly balance at a glance.
- **Advanced Sorting:** Sort your transactions by Date, Amount, Title, or Transaction Type.
- **Data Persistence:** All data is securely saved on your device using Core Data.
- **Comprehensive Filtering:** Utilize a wide variety of filters to customize your list of transactions.
